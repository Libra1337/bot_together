# AI 生图恢复与配置页面设计

## 目标

恢复 Official QQBot 的 AI 生图能力，并在管理后台新增独立的生图配置子页面。管理员可以配置 OpenAI 兼容的生图 API、检测实际生成结果，并在保存后立即让 Bot 使用新配置。聊天 AI 与生图 AI 必须完全分离，任一配置变更都不能覆盖另一方。

## 功能范围

- 支持 `/生图 描述` 显式命令。
- 支持“帮我画一张……”等旧版自然语言触发方式。
- 生图请求优先于普通 AI 对话，不把绘图描述发送给聊天模型。
- 群聊与私聊均直接发送 QQ 图片消息。
- 同一用户在群聊和私聊共用冷却时间，默认 60 秒。
- 封禁用户沿用现有封禁规则，不能调用生图服务。
- 本次不实现图片理解；QQ 图片附件进入多模态聊天属于独立功能。

## 配置模型

在 `config.yaml` 中新增独立的 `image_ai` 配置段：

```yaml
image_ai:
  enabled: false
  base_url: ""
  api_key: ""
  model: "grok-imagine-1.0-fast"
  size: "1024x1024"
  cooldown_seconds: 60
```

- `base_url` 是 OpenAI 兼容 API 的版本根地址，运行时请求 `{base_url}/images/generations`。
- `api_key` 只写入服务器配置，不在网页或日志中完整回显。
- `size` 由后台下拉框选择，避免提交无效尺寸。
- 生图配置优先读取 `config.yaml`，仅在 YAML 字段缺失时回退对应环境变量，保持与聊天 AI 当前生效规则一致。
- 缺少地址、Key 或模型时即使开关开启也不能发起外部请求，并向用户返回明确的中文提示。

## 管理后台

- 新增页面 `/dashboard/image-ai`，导航名称为“AI 生图”。
- 页面沿用现有 Dashboard 会话认证，未登录用户跳转到登录页。
- 表单字段包括启用开关、API 地址、API Key、模型名称、图片尺寸和用户冷却秒数。
- API Key 只显示脱敏状态；输入框留空时保留当前 Key。
- “检测生图”使用表单中的配置真实调用一次 `/images/generations`，不保存配置。
- 检测成功后显示生成结果预览，兼容 URL 和 `b64_json`。
- “保存并重启”先检测，再原子更新 `config.yaml`，只重启 `official-qqbot`。
- 重启失败时恢复旧配置并尝试恢复旧 Bot；审计日志不记录 API Key。
- 页面保持现有中文、蓝色按钮、轻圆角和短过渡风格，并支持移动端。

## 生图客户端

新增独立的生图模块，负责：

- 判断自然语言是否为生图请求并提取提示词。
- 使用 `httpx` 调用 OpenAI 兼容的 `/images/generations`。
- 发送 `model`、`prompt`、`n: 1` 和 `size`。
- 接受 `data[0].url` 或 `data[0].b64_json`。
- 将网络超时、HTTP 错误、内容审核和无图片响应转换为不泄露上游响应体的中文错误。
- 用用户统一标识记录进程内冷却；冷却只在成功开始外部调用时占用，剩余时间向上取整显示。

## QQ 图片发送

生成成功后使用 QQ 官方富媒体两步发送流程：

1. 根据会话类型调用群聊或私聊文件上传接口，提交 `file_type: 1`、图片 URL 或 Base64 数据，并设置 `srv_send_msg: false`。
2. 读取上传结果的 `file_info`，再发送 `msg_type: 7` 的图片消息，关联原始 `msg_id` 和递增的 `msg_seq`。

若上传或最终发送失败，记录不含图片数据的错误摘要，并向用户发送中文失败消息。Base64 内容、API Key 和完整上游响应不得进入日志或控制台审计记录。

## 消息路由

消息处理顺序保持现有功能优先级：

1. 状态会话与现有指令。
2. 天气和链接解析。
3. AI 生图识别与执行。
4. 模糊指令匹配。
5. 普通 AI 对话。

`/生图` 未附带描述时返回用法提示。生图关闭或配置不完整时，命中的生图请求直接返回状态提示，不降级成普通 AI 聊天。

## 失败处理

- 无效 URL、空模型、空 Key、非法尺寸或冷却值：后台立即提示，不请求上游。
- 网络超时或不可连接：提示生图服务连接失败。
- 非 2xx：只显示 HTTP 状态码，不显示可能包含敏感信息的响应体。
- 响应没有 URL 或 Base64：提示接口返回中没有图片。
- QQ 富媒体上传失败：提示图片发送失败，日志记录状态码和短错误类型。
- 保存后 Bot 重启失败：恢复原配置，管理后台保持在线。

## 测试范围

- 生图请求识别、提示词提取和非生图文本排除。
- 配置读取、环境变量回退、Key 脱敏、字段校验及原子保存。
- API URL 拼接、请求体、URL 响应、Base64 响应、超时和异常响应。
- 用户冷却、群聊与私聊共用统一用户标识。
- QQ 群聊和私聊富媒体上传及 `msg_type: 7` 发送载荷。
- 生图路由优先于普通 AI 对话，关闭与未配置状态不调用上游。
- 后台页面认证、中文字段、连接检测、保存重启、失败回滚和审计脱敏。
